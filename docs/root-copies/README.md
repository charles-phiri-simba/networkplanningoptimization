# SNIP root copies

Convenience mirrors of selected SNIP phase architecture and specification markdown files that previously lived at the repository root.

**Authoritative locations:**

| Document type | Canonical path |
|---------------|----------------|
| Architecture | `docs/architecture/SNIP-PHASE-*-ARCHITECTURE.md` |
| Specification | `docs/implementation/SNIP-PHASE-*-SPECIFICATION.md` |
| Completion report | `docs/implementation/SNIP-PHASE-*-COMPLETION-REPORT.md` |
| Implementation context | `docs/implementation/SNIP-IMPLEMENTATION-CONTEXT.md` |
| Implementation status | `docs/implementation/SNIP-IMPLEMENTATION-STATUS.md` |

Files in this directory are duplicates for easy discovery. When editing phase documentation, update the canonical path under `docs/architecture/` or `docs/implementation/`, then refresh the matching file here if a root copy is still maintained.
